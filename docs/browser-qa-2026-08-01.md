## 关键断言

- “跨部门同事一直催我给项目数据，负责人还没有回复……”识别为“跨部门伙伴＋催进度”；无明确渠道时使用即时消息模板，并显示低置信度“请确认”。
- 普通短语“我不知道怎么说明时间和下一步”不再被地址规则误脱敏；真实地址仍会在浏览器发送前清理，并在服务端二次清理。
- 准备页显示“服务端规则＋知识编排”，训练页只把 DeepSeek/港话通描述为回合阶段尝试调用。
- 第二轮后出现“现在结束并复盘”；复盘显示逐轮推进轨迹，复制行动卡成功，提示其不包含原始输入或逐轮回答。
- 评委导览依次覆盖第 1、4、5 幕；第四幕承担核对后加载 `DEMO-01`，显示正反选择的数值与人物反应对比。
- 评委导览开始前和完整退出后 `localStorage` 均为空，底层主线仍为第一幕，状态数值及故事图未变化。
- 两个视口的 `body.scrollWidth` 与 `documentElement.scrollWidth` 均等于视口宽度；浏览器控制台 0 error、0 warning。
- 390×844 下语音工具自动改为两列，逐轮回应、隐私弹层和本机录音入口
  均可达；1440×1024 下主线/训练/自定义输入没有遮挡关键动作。
- 移动端同时显示“进入完整主线”“退出演示”，下一段与底部进入完整五幕主线动作可达。
