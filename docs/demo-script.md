# Demo script

## 90-second version

**0–10 seconds — problem**

“普通语言 App 教你这句话怎么说，但香港职场真正困难的是：同一句话
在不同关系里，为什么会产生完全不同的后果。”

**10–40 seconds — custom reality training**

从首页快速扫过三条入口：电影式主线、十二项训练手册、我的真实情境。
打开“我的真实情境”，输入一个不含真实姓名和机构的跨部门催办难题。
展示浏览器端隐私处理回执、编排来源、关系/渠道/重点的置信度、匹配的
技能卡和可修正设置。现场输入一句自己的回答，展示：

- DeepSeek 生成 NPC 即时反应；
- 港话通给出自然度、礼貌度、商务适配和更港式改写；
- AI 教练按目标清晰、具体性、主人翁意识、关系维护、风险透明和下一步
  六项行为判断是否真正推进工作，而不只判断粤语；
- 任务复盘给出逐轮推进轨迹、六维量表、依据来源和不含原始回答的
  “现实行动卡”。

**40–70 seconds — selected mainline showcase**

返回首页点击“90 秒评委演示”。快速经过第一幕关系建立，在第四幕选择
“承担核对”，展示它与“甩锅”的信任/专业度差异和陈嘉敏接过补救计划的
关键后果镜头；随后进入第五幕范围收口和学习报告。

说明这条精选导览不调用模型、不写存档，退出后完整五幕进度保持不变。

**70–90 seconds — AI boundary and value**

“模型负责人物反应和语境点评，程序负责节点、分数边界和回退。它
不是聊天框，也不会把剧情带飞。”

“粤商通不只教你点讲，而是让你练习怎样把一段真实工作推进。下一步
可以服务企业入职培训、来港人才和高校职业教育。”

## Three-minute version

1. 用 25 秒说明目标用户：赴港工作者与企业新员工；
2. 浏览十二项训练并用筛选器收窄场景；
3. 输入一个自定义真实难题，展示先脱敏再编排的流程；
4. 完成两到三轮训练，展示双模型职责分工与六维行为量表；
5. 打开来源抽屉，展示技能卡与香港官方资料的绑定；
6. 打开评委演示，展示第 1、4、5 幕精选路径，再进入完整五幕主线；
7. 切换运行模式并刷新，说明 Provider、静态保底与本机断点；
8. 用架构图解释模型边界、数据最小化和企业训练扩展潜力。

## Live-demo fallback

- 首选：AI 即兴模式；
- 需要快速证明主线：点击“90 秒评委演示”，该路径零网络且不写存档；
- API 不可用：点击右上角切换标准剧情；
- 浏览器没有粤语音色：隐藏语音演示，不影响主流程；
- 极端现场故障：播放预录的 90 秒完整通关视频。
