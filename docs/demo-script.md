# Demo script

## 90-second version

**0–15 seconds — problem**

“普通语言 App 教你这句话怎么说，但香港职场真正困难的是：同一句话
在不同关系里，为什么会产生完全不同的后果。”

**15–45 seconds — interaction**

从主菜单打开“7 个情境训练”，快速扫过任务澄清、坏消息沟通、柔性
跟进和范围控制等真实工作任务。选择“先确认，再开工”，先展示本轮
任务和隐藏关系风险，再进入现场。Vincent 说：“呢份新任务你今日帮我
跟一跟，尽快畀我就得。”现场输入一句自己的回答。展示：

- DeepSeek 生成 NPC 即时反应；
- 港话通给出自然度、礼貌度、商务适配和更港式改写；
- AI 教练判断玩家是否真正确认目标、交付物和时间，而不只判断粤语；
- 任务复盘给出得分、隐藏风险解释和可直接带回工作的复用句式。

返回训练库，指出四名主要 NPC 在主线与训练中各有至少三次可玩互动，
完成记录和最佳分数只保存在本机。

**45–70 seconds — AI depth**

“模型负责人物反应和语境点评，程序负责节点、分数边界和回退。它
不是聊天框，也不会把剧情带飞。”

打开五幕主线并切回“标准剧情”，说明即使模型、额度或网络暂时不可用，
主线和所有预写训练路径仍可完整运行。

**70–90 seconds — value**

展示训练任务复盘和五幕学习报告。

“粤商通不只教你点讲，而是让你练习怎样把一段真实工作推进。下一步
可以服务企业入职培训、来港人才和高校职业教育。”

## Three-minute version

1. 用 25 秒说明目标用户：赴港工作者与企业新员工；
2. 浏览七项训练，解释“实际任务—隐藏关系风险—可迁移模板”结构；
3. 进入任务澄清训练并自由输入一句回应，展示双模型职责分工；
4. 打开任务复盘，展示得分、港式改写和现实复用句式；
5. 再打开范围控制或坏消息沟通，证明同一角色并非只有一个情节；
6. 进入五幕主线，展示地点建立镜头、人物档案和现场后果；
7. 切换运行模式并刷新，说明 Provider、静态保底与本机断点；
8. 用架构图解释模型边界、数据最小化和企业训练扩展潜力。

## Live-demo fallback

- 首选：AI 即兴模式；
- API 不可用：点击右上角切换标准剧情；
- 浏览器没有粤语音色：隐藏语音演示，不影响主流程；
- 极端现场故障：播放预录的 90 秒完整通关视频。
