# 三分钟评委演示脚本

录制规格：1920×1080 横版、MP4 / H.264、3:00 以内、无平台水印。

## 0:00–0:20｜问题与产品入口

画面：品牌标题 → 首页四个动作。

旁白：普通语言 App 教你一句话怎么说；香港职场真正困难的是，同一句话在不同关系与责任边界里会产生不同后果。粤商通用 AI 互动视觉小说，让用户在低风险环境中练习怎样把工作推进。

点击：首页“3 分钟评委演示”。

## 0:20–0:45｜第一段：五幕主线

画面：金钟建立镜头与“同一句粤语，先看关系与任务”。

旁白：五幕主线先建立人物、任务和文化语境。模型可以增强角色表演，但故事节点、分数边界和离线回退始终由程序控制。

点击：“看专题训练”。

## 0:45–1:15｜第二段：12 项训练

画面：阿朗跨部门柔性跟进；预置粤语回应已经填好。

旁白：训练库按关系、渠道、技能和难度组织 12 个高频任务。现场可以编辑回应；这里直接使用准备好的最低范围、负责人和时间表达。

点击：“展示离线参考反馈” → “看现实情境”。

## 1:15–1:50｜第三段：我的现实情境

画面：预置“跨部门同事催数据”文本；停留两秒让评委看清，再点击生成。

旁白：现实难题先在浏览器脱敏，再由共享规则判断关系、渠道和训练重点。这个样例稳定识别为跨部门伙伴与柔性跟进；渠道没有明确线索，所以要求用户确认。文本可现场改写，演示状态不会写入存档。

点击：“生成匿名演示训练” → “进入危机抉择”。

## 1:50–2:20｜第四段：关系后果

画面：第四幕危机；选择“承担核对”，展示陈嘉敏接过补救计划、正反综合变化与四项数值。

旁白：系统不只判断粤语自然不自然，还让用户看到承担核对与甩锅对信任、专业度和下一步的不同影响。

点击：“承担核对” → “看学习复盘”。

## 2:20–2:40｜第五段：学习复盘

画面：第五幕范围收口与三条学习报告。

旁白：复盘把语言建议变成范围、指标、负责人、更新时间和下一步，帮助用户把练习带回真实工作。

## 2:40–2:55｜AI 边界与稳定性

画面：切到路演 PPT 第 6、7 页。

旁白：DeepSeek 负责人物反应与关系后果，港话通负责香港商务表达复盘；程序掌握故事图、隐私和失败回退。没有模型、语音或网络，桌面主流程仍然完整。

## 2:55–3:00｜收尾

画面：路演 PPT 尾页或品牌标题。

旁白：粤商通，不只教你点讲，更让你练习点样把件事倾成。

## 录屏保底

- 模型或网络不稳定：全程只录“3 分钟评委演示”，它不发网络请求；
- 语音未配置：直接使用已经填好的键盘文本；
- 现场误操作：使用“上一段”返回，不必重启应用；
- 极端故障：播放已经验收过的最终 MP4，不临场等待 API。
