# Demo script

## 90-second version

**0–15 seconds — problem**

“普通语言 App 教你这句话怎么说，但香港职场真正困难的是：同一句话
在不同关系里，为什么会产生完全不同的后果。”

**15–45 seconds — interaction**

进入第一幕。客户问：“你份方案几完整，不过点解我哋要而家就转？”

选择“我先讲唔转嘅风险，再用两星期试点验证”。展示：

- NPC 即时追问；
- 信任和专业度上升；
- AI 教练解释为什么“可验证行动”比制造紧迫感更可信。

**45–65 seconds — AI depth**

“模型负责人物反应和语境点评，程序负责节点、分数边界和回退。它
不是聊天框，也不会把剧情带飞。”

切换“AI 即兴 / 标准剧情”。

**65–90 seconds — value**

展示学习报告。

“粤商通把语言、文化、关系和后果放进同一条体验。下一步可以服务
企业入职培训、来港人才和高校职业教育。”

## Three-minute version

1. 用 25 秒说明目标用户：赴港工作者与企业新员工；
2. 完成第一幕的一个选择；
3. 故意选择第二幕的较差回应，展示不是所有“地道粤语”都合适；
4. 切换运行模式，说明 DeepSeek/HKGAI Provider 与静态保底；
5. 完成第三幕并展示结局；
6. 用架构图解释模型边界、数据最小化和可扩展性。

## Live-demo fallback

- 首选：AI 即兴模式；
- API 不可用：点击右上角切换标准剧情；
- 浏览器没有粤语音色：隐藏语音演示，不影响主流程；
- 极端现场故障：播放预录的 90 秒完整通关视频。
