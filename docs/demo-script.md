# Demo script

## 90-second version

**0–15 seconds — problem**

“普通语言 App 教你这句话怎么说，但香港职场真正困难的是：同一句话
在不同关系里，为什么会产生完全不同的后果。”

**15–45 seconds — interaction**

进入第一幕，切到“AI 即兴”。直属经理问：“朝早十点同客户开会，
你准备好点样介绍自己未？”现场输入一句自己的回答。展示：

- DeepSeek 生成 NPC 即时反应；
- 港话通给出自然度、礼貌度、商务适配和更港式改写；
- 信任和专业度上升；
- AI 教练解释为什么商务自我介绍应先讲角色与价值，而不是从履历背起。

**45–65 seconds — AI depth**

“模型负责人物反应和语境点评，程序负责节点、分数边界和回退。它
不是聊天框，也不会把剧情带飞。”

切回“标准剧情”，再刷新页面展示断点续玩。说明即使模型、额度或网络
暂时不可用，五幕主线仍可完整通关。

**65–90 seconds — value**

展示学习报告。

“粤商通把语言、文化、关系和后果放进同一条体验。下一步可以服务
企业入职培训、来港人才和高校职业教育。”

## Three-minute version

1. 用 25 秒说明目标用户：赴港工作者与企业新员工；
2. 在第一幕自由输入一句回应，展示双模型职责分工；
3. 在第四幕故意选择甩锅回应，展示危机中“语言正确”也可能破坏信任；
4. 切换运行模式并刷新，说明 Provider、静态保底与本机断点；
5. 完成第五幕并展示包含五个学习点的结局；
6. 用架构图解释模型边界、数据最小化和可扩展性。

## Live-demo fallback

- 首选：AI 即兴模式；
- API 不可用：点击右上角切换标准剧情；
- 浏览器没有粤语音色：隐藏语音演示，不影响主流程；
- 极端现场故障：播放预录的 90 秒完整通关视频。
