# CantoneseBiz 三分钟桌面 Demo 镜头单

输出规格：1920×1080 横版、MP4 / H.264、3 分钟以内、无平台水印。

## 录制前设置

- 使用 Chrome 或 Edge，窗口固定为 1920×1080，缩放 100%；
- 隐藏书签栏、通知和个人账号信息；
- 前端与后端先完成健康检查；
- 首页保持第一幕初始状态；
- 使用已经预置的两段输入，不现场组织长句；
- 语音、真实模型与网络不作为录屏依赖。

## 录制后验收

- 用媒体信息工具确认 H.264、1920×1080、总时长不超过 3:00；
- 文件不超过 300MB；
- 从头播放，确认声音、字幕、鼠标和转场没有卡顿；
- 在另一台电脑或播放器打开；
- 保留原始录屏，只上传最终压缩版。
