用途：为“我的现实情境”动态模拟提供比预置训练更广的环境覆盖。

## 共同约束

- 1536×1024 横向，高端半写实电影插画／现代香港商务视觉小说；
- 保持参考锚点中的同一张脸、年龄、发型、体型、主服装和配饰，不重设计；
- 当前 NPC 位于右侧并面向左侧玩家，35–50mm 眼平镜头；
- 下方 40% 不放面部、关键手势或关键道具，右上状态区低对比；
- 使用 `#050B18`、`#091329`、`#0C1933`、`#F4BE55`、`#D79B29`、
  `#BA89FF`、`#6ADFE7` 固定色板；
- 无可读文字、公司标志、品牌、签名、水印、真实人物或现有作品角色。
