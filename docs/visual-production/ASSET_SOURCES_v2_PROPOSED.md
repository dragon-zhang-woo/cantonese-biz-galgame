# Asset Sources v2 — Proposed

## 原创与许可原则

- 所有角色、场景、道具与故事图均为项目原创。
- AI生成图不得刻意描绘真实人物、现有角色、商标或特许经营内容。
- 每个正式资产必须保留生成记录、提示词版本、参考图来源和编辑谱系。

## 新资产记录要求

每个资产必须记录：

- 资产 ID；
- 文件路径；
- 角色与场景；
- 故事幕次；
- 模型；
- 生成日期；
- 提示词版本；
- 参考图；
- 父资产；
- 生成或编辑 ID；
- QA结果；
- 许可备注。
