## 最终生成提示词

使用提供的三张项目原创参考图，生成一张单一、完整、非拼贴的
1536×1024 横向游戏场景。严格保持陈嘉敏与角色锚点为同一人物：相同脸型、
年龄、五官、黑色整洁发型、炭灰色结构化西装、暖米白真丝衬衫和低调耳饰；
不要重新设计人物，不要改变年龄、服装或发型。

场景位于雨夜香港中环的高层项目战情室，延续参考场景的玻璃雨痕、冷蓝城市
灯光、深海军蓝室内层次和克制的暖金边缘光。陈嘉敏位于画面右侧约三分之一处，
身体略微朝向左侧玩家，表情由质询转为谨慎认可，但仍保持专业、理性和克制。

画面左侧中部，一只第一人称玩家的手从画外将一页无文字的补救计划推向桌面
中央；纸面只能出现三个抽象图形区块，暗示“影响范围、负责人、更新时间”，
不得出现任何可读文字、数字、公司名称或标志。陈嘉敏一只手自然停在文件旁，
准备接过计划；手指数量与关节必须自然。背景中的数据屏只显示抽象线条和色块。

使用 35–50mm 眼平电影镜头，高端半写实电影插画、现代香港商务视觉小说质感。
人物右置，左侧保留叙事空间；下方 40% 不放面部、关键手势或关键道具，供游戏
对话控制台覆盖；右上状态栏区域保持低对比和视觉安静。

固定色板：`#050B18`、`#091329`、`#0C1933`、`#F4BE55`、`#D79B29`、
`#BA89FF`、`#6ADFE7`；仅用少量 `#FF745E` 表现危机余韵。画面应呈现
“事实尚未完全查清，但责任、负责人和更新时间已经被接住”的确定感。

禁止：可读文字、乱码、品牌、公司标志、签名、水印、二维码、现有影视或动漫
角色、真实公众人物、夸张动漫风、塑料感写实、通用企业图库感、霓虹赛博朋克、
分屏、拼贴、HUD、对话框、字幕、低清晰度、畸形手部、重复人物。
