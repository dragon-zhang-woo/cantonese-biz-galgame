# 《粤商通》剧情—资产映射表

## 第一幕：金钟入职

- 核心问题：商务自我介绍应该先讲角色与价值。
- 主角色：Vincent。
- 主场景：公司前台。
- 新增建议：
  - 金钟清晨建立镜头；
  - 电梯反射中的玩家；
  - Vincent 推文件夹近景；
  - Vincent 中性/认可/纠正反应立绘。

## 第二幕：中环初会

- 核心问题：先接住风险顾虑，再提出可验证的小步行动。
- 主角色：陈嘉敏。
- 主场景：客户会议室。
- 新增建议：
  - 中环黄昏建立镜头；
  - 未签署方案桌面；
  - 陈嘉敏停笔抬眼；
  - 追问成本控制的反应立绘。

## 第三幕：茶水间试探

- 核心问题：不要把“再睇下”过早解释为拒绝。
- 主角色：阿朗。
- 主场景：公司茶水间。
- 新增建议：
  - 蓝调时刻茶水间全景；
  - 两杯咖啡近景；
  - 远处会议室倒影；
  - 阿朗会意/试探/提醒立绘。

## 第四幕：危机补救

- 核心问题：危机沟通必须给出事实范围、负责人和更新时间。
- 主角色：陈嘉敏。
- 主场景：项目战情室。
- 新增建议：
  - 雨夜中环建立镜头；
  - 两组不一致数据图形；
  - 手机冷光侧脸；
  - 玩家核对清单；
  - 陈嘉敏高压/缓和反应立绘。

## 第五幕：湾仔收口

- 核心问题：预算不变时先重组范围和价值，而不是立刻降价。
- 主角色：何太。
- 主场景：老字号茶餐厅。
- 新增建议：
  - 湾仔夜街建立镜头；
  - 茶杯和一页计划近景；
  - 试点范围图形化摘要；
  - 何太倾听/追问/认可立绘；
  - 玩家离开茶餐厅的第一人称结尾。

## 资产优先级

### P0：先做

1. 四名 NPC 的角色锚点；
2. 陈嘉敏第二幕与第四幕的同一身份重制/校准；
3. 四名 NPC 的中性和关键反应立绘；
4. 五张主场景的人物一致性校准。

### P1：增强剧情

1. 六张建立镜头；
2. 十二张剧情插图；
3. 雨、玻璃反射、城市散景等覆盖层。

### P2：路演与宣传

1. 五幕横向故事拼图；
2. 四角色阵容海报；
3. 评委演示用架构与场景结合图；
4. 商务粤语“关系后果”概念海报。
