# GPT Image 2 提示词模板

## 场景主图模板

```text
使用角色锚点图中的同一个角色，为原创互动视觉小说《粤商通 CantoneseBiz》生成一张新的主场景图。

剧情：
[幕次、地点、当前对话、角色此刻的意图]

人物连续性：
必须保持输入锚点图中角色完全相同的脸型、年龄、发型、肤色、体型、服装和配饰。不要重新设计角色。

风格：
高端半写实电影插画，现代香港商务视觉小说。自然皮肤、真实织物、克制表情、电影级光线。

构图：
横向 1536×1024。眼平视角，35–50mm 电影镜头感。
角色位于画面右侧，面向左前方玩家。
下方约40%保持安静用于游戏对话界面。
右上角保持低对比以便状态面板显示。

约束：
原创虚构；无真实人物；无现有角色；无品牌；无Logo；无水印；无可读文字；不改变角色身份。
```

## 表情立绘编辑模板

```text

```
