本文是《粤商通》角色、场景、镜头、服装、色彩、生成流程和验收标准的唯一视觉规范。`CHARACTER_BIBLE.md`、`STORY_ASSET_MAP.md` 与提示词模板不得与本文冲突。

## 1. 项目视觉目标

《粤商通》是一部以香港职场关系后果驱动的商务粤语 AI 互动视觉小说。画面必须同时传达：

1. 香港商务环境的可信度；
2. 视觉小说的人物戏剧性；
3. 职场沟通的克制、压力与关系距离；
4. 对现有网页界面的构图适配；
5. 原创、可追溯、可重复编辑的资产生产流程。

### 不可破坏的约束

- 所有人物、故事与图像均为原创虚构，不模仿真实人物或现有影视、动漫、游戏角色。
- 主场景采用全屏电影化构图，当前说话 NPC 通常位于画面右侧。
- 画面下方约 40% 不放面部、关键手势、关键道具或重要叙事信息，用于对话控制台。
- 右上角状态面板区域避免高对比面部和密集物体。
- 延续深蓝、暖金、低饱和紫、青色的视觉体系。
- 禁止水印、品牌标志、可辨识公司 Logo、无关文字和随机招牌。
- 主场景规格为 1536×1024；角色锚点规格为 1024×1536。
- 后续角色素材必须使用已批准锚点图作为输入，不得每次从纯文本重新生成“同一个人”。
- 视觉扩展不得修改五幕故事图、分数逻辑或 `nextSceneId`。

## 2. 总体美术语言

### 风格

**高端半写实电影插画／现代香港商务视觉小说。**

- 约 70% 电影摄影的光线、材质、空间和人体比例；
- 约 30% 精品视觉小说的角色清晰度、面部可读性和情绪控制；
- 不采用夸张日漫大眼、塑料皮肤、网红写真滤镜、通用企业图库感或霓虹赛博朋克堆砌；
- 不追求新闻照片式完全写实，以降低跨图年龄、五官和体型漂移。

### 材质

- 玻璃：反射真实但不抢戏；
- 金属：拉丝铝、香槟金或深色钢，避免廉价镀铬；
- 木材：胡桃木、深茶色木饰面；
- 织物：羊毛西装、细针织、真丝或棉质衬衫，褶皱自然；
- 皮肤：保留轻微毛孔和真实肤色，不磨皮、不呈蜡像感；
- 可使用极轻微电影颗粒，不得明显复古、污损或过度锐化。

## 3. 镜头与构图规则

### 游戏主场景

- 横向 1536×1024；
- 眼平或略低于眼平；
- 35–50mm 电影镜头感，禁止超广角畸变；
- NPC 位于画面右侧 55%–82% 区域，面向左侧或左前方的第一人称玩家；
- 人物采用腰部以上或三分之二身构图；
- 角色看向玩家所在方向，不直视观众镜头；
- 下方 40% 保持安静，右上 20% 保持低对比；
- 左侧承担地点、天气和环境叙事；
- 背景可轻度虚化，但香港城市线索和办公室层次必须可辨识；
- 禁止鱼眼、自拍视角、强烈荷兰角、过度浅景深和强镜头光斑。

### 例外镜头

- 第四幕危机可使用 50–65mm 的更紧镜头和极轻微 2–4° 倾斜；
- 建立镜头可使用 24–35mm 广角，但不承担角色面部特写；
- 道具切片可使用 70–90mm 近摄感，背景简洁且没有可读敏感文字。

### 角色立绘

- 透明背景或纯深海军蓝背景；
- 标准姿态为 3/4 正面，人物看向画面左侧；
- 半身必须从头顶到腰部完整，不裁掉关键手势；
- 全身锚点必须包含鞋子；
- 表情变化只能改变眉眼、嘴角、轻微头部角度和手势，不得改变脸型、年龄、发型、体型和服装结构。

## 4. 服装连续性

- 当代香港商务环境，剪裁合体、克制、干净，不出现品牌标志；
- 不使用校服感、偶像制服、夸张礼服或黑帮式全黑造型；
- 每名角色只有一套主线固定服装；
- 同一天只允许脱外套、卷袖、松开一粒扣、增加雨水、褶皱或疲态；
- 不得改变衬衫颜色、发型、眼镜款式、首饰和鞋型；
- 每次提示都要明确：same face, same age, same hairstyle, same body proportions, same primary outfit, same accessories, no redesign。

## 9. 五幕故事与视觉重点

### 第一幕：金钟入职

- 冲突：Vincent 要求玩家准备十点客户会面的自我介绍；
- 正确策略：先讲负责范围和客户价值，再补经历；
- 错误策略：从学校和履历开始长篇介绍；
- 视觉重点：电梯倒影、清晨暖金光、被推到玩家面前的项目文件、Vincent 克制的点头或停顿。

### 第二幕：中环初会

- 冲突：陈嘉敏承认方案完整，却追问为什么必须现在转型；
- 正确策略：先回应延后的风险，再提出两周、小范围、可撤回试点；
- 错误策略：制造没有证据的“三个月窗口”；
- 视觉重点：未签署文件、停笔抬眼、中环黄昏、暖光与玻璃冷蓝反射。

### 第三幕：茶水间试探

- 冲突：阿朗询问玩家如何理解“再睇下”；
- 正确策略：识别客户对交付风险、责任边界和退出机制仍不放心；
- 错误策略：直接判定客户已拒绝；
- 视觉重点：两杯咖啡、非正式沟通距离、远处仍亮着的会议室。

### 第四幕：危机补救

- 冲突：试点数据与上周说法不一致，陈嘉敏要求今晚交代；
- 正确策略：核对差异来源，并承诺九点前提供事实范围、负责人、影响和补救方案；
- 错误策略：强调数据来自客户并先划清责任；
- 视觉重点：雨夜玻璃、手机冷光、两组数据、克制高压，不使用拍桌或怒吼。

### 第五幕：湾仔收口

- 冲突：客户愿意试，但预算不会增加；
- 正确策略：范围减半、指标不减，达标后进入第二阶段并形成书面确认；
- 错误策略：主动降价一成以求当天签约；
- 视觉重点：茶餐厅暖金灯光、一页试点计划、何太极克制的认可、玩家走入湾仔夜色。

## 10. 生成流程

### A. 锁定人物

1. 每名角色生成 4 个锚点候选；
2. 只批准 1 个官方锚点；
3. 在生成台账记录生成 ID、提示词版本、输入图和选择理由；
4. 后续立绘与场景必须使用该锚点作为图像输入；
5. 不允许在新会话中只凭文字重新生成同一角色。

### B. 锁定场景风格

1. 选择一张现有主场景作为风格参考；
2. 保持调色、材质、光线和构图语言，只改变一个主要变量；
3. 人物、背景和天气同时变化时拆成多步编辑；
4. 陈嘉敏第四幕必须以第二幕角色图作为连续性输入。

### C. 主场景提示必须包含

地点与时间、当前剧情动作、角色锚点不变量、镜头和视线、下方 UI 安全区、右上状态区、固定色板、允许变化、禁止变化、无文字／品牌／水印约束。

### D. 小范围编辑固定语法

```text
仅修改：[明确的一项变化]。
必须保持：人物身份、脸型、年龄、发型、体型、服装、配饰、构图、镜头角度、背景几何、色彩分级和画面尺寸。
不要改变其他任何内容。
```

## 11. QA 与准入

每张图至少检查：

1. 角色身份一致；
2. 年龄、脸型、发型和体型一致；
3. 主服装与配饰一致；
4. 手部与道具正确；
5. 视线方向正确；
6. 下方 UI 安全区成立；
7. 右上状态区不冲突；
8. 香港商务环境可信；
9. 固定色板成立；
10. 无意外文字、Logo、水印和版权风险。

低于 8/10 不进入正式资产目录。未正式检查的项目必须记录为 `not_formally_scored`，不得凭空写成通过。

状态枚举：`draft`、`candidate`、`approved`、`rejected`、`superseded`、`archive`。

## 13. 文件命名与目录

命名格式：

```text
[类型]-[角色或地点]-[幕]-[状态]-v[版本].[扩展名]
```

示例：

```text

char-chen-jiamin-halfbody-probing-v02.png
scene-central-meeting-act2-neutral-v03.png

```

禁止使用 `final.png`、`final2.png`、`new.png`、`好看版.png` 或 `未命名.png`。

## 14. 版本冻结

角色锚点、主服装和标准中性半身全部获批后，角色进入冻结状态：

- 新素材不得改变五官、年龄、发型和主服装；
- 重设计升级大版本，例如 `CH-02 v2.0`；
- 表情、动作和灯光变化升级小版本，例如 `v1.2`；
- 被替换文件移入 `archive/`，不得覆盖后丢失来源；
- 任何批量生成都必须从冻结版本开始。
