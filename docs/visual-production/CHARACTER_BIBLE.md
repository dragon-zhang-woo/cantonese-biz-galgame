# 《粤商通》人物设定与立绘清单

本文件是 `VISUAL_BIBLE.md` 的角色执行版；若两者出现冲突，以视觉资产圣经为准。

## CH-00 玩家／新员工

- 身份：初次进入香港商务环境的普通话母语新员工。
- 呈现：第一人称，不建立可重复正脸。
- 可见元素：手、袖口、文件、手机、肩部、模糊倒影。
- 固定服装：深灰或海军蓝初级商务套装，米白衬衫。
- 禁止：在不同插图里随机生成不同玩家面孔；抢走 NPC 视觉中心。

## CH-01 Vincent 梁志诚

- 职务：项目带教经理／客户项目负责人。
- 年龄：36。
- 视觉关键词：修长、整洁、海军蓝、暖金、冷静审视。
- 主服装：深海军蓝羊毛西装、米白衬衫、暖金深蓝细纹领带、黑鞋、金属腕表。
- 道具：文件夹、平板。
- 表情：中性、轻微认可、礼貌纠正、严肃提醒。
- 场景主光：金钟清晨暖金边缘光 + 室内深蓝阴影。

## CH-02 陈嘉敏

- 职务：区域业务总监，客户方决策者。
- 年龄：38。
- 视觉关键词：成熟、理性、风险意识、炭灰、紫灰。
- 主服装：炭灰西装外套、暖米白真丝衬衫、深色直筒裤、低跟鞋、哑光金属耳饰。
- 道具：文件、手机、金属笔。
- 表情：中性审阅、礼貌质疑、继续追问、危机高压、轻微缓和。
- 连续性：第二幕与第四幕必须使用同一锚点；第四幕不得更换服装。
- 场景主光：
  - 第二幕：中环夕阳暖光 + 玻璃冷蓝反射；
  - 第四幕：雨夜青蓝冷光 + 极少量危机橙红。

## CH-03 阿朗

- 职务：香港本地项目经理。
- 年龄：30。
- 视觉关键词：放松、敏锐、有人情味、深青蓝。
- 主服装：深青蓝轻商务夹克、灰蓝针织 Polo、深色长裤、棕色休闲皮鞋。
- 道具：两杯无标识咖啡、手机。
- 表情：会意、试探、提醒、轻微担忧。
- 禁止：嬉皮笑脸、八卦夸张、街头潮人化。
- 场景主光：蓝调时刻的青蓝环境光 + 茶水间暖光。

## CH-04 何太

- 职务：部门直属经理／最终复盘负责人。
- 年龄：46。
- 视觉关键词：沉稳、务实、深梅紫、暖金。
- 主服装：深梅紫结构化外套、米色内搭、深色下装、低跟鞋、暖金腕表。
- 道具：茶杯、一页项目摘要、金属笔。
- 表情：平静倾听、追问、明确要求、轻微认可。
- 禁止：严厉刻板的“女上司”脸谱、夸张珠宝、过度年轻化。
- 场景主光：茶餐厅暖金灯光 + 湾仔夜色冷蓝。
