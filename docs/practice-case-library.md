# 《粤商通》实用情境训练库扩充方案

更新日期：2026-07-26

## 产品目标

保留现有五幕电影化主线作为比赛演示路径，新增七个可独立反复训练的
香港职场情境。玩家可以从首页进入“情境训练库”，针对真实任务练习
自由回答、查看双模型反馈并重试，不必每次完整通关五幕。

## 七个新增训练情境

### P01 Vincent：先确认，再开工

- 场景：金钟项目作战室，早会后。
- 实用任务：面对含糊指令，确认目标、交付物和截止时间。
- 隐藏风险：新人为了显得积极而直接答应，最后做错方向。
- 训练技能：澄清问题、向上管理、任务复述。

### P02 何太：两件急事，只能先做一件

- 场景：金钟开放办公室，午前排期冲突。
- 实用任务：向直属经理说明资源冲突并提出优先级方案。
- 隐藏风险：把“忙不过来”说成抱怨，或不说明取舍后果。
- 训练技能：优先级协商、风险上报、可执行建议。

### P03 Vincent：坏消息要几点讲

- 场景：黄昏项目区，交付物确认延期。
- 实用任务：在客户发现前主动报告延期并提出补救时间表。
- 隐藏风险：等到信息完全确定才说，导致对方失去准备时间。
- 训练技能：坏消息沟通、责任边界、更新时间。

### P04 阿朗：午饭不是面试

- 场景：中环午市茶餐厅，与跨部门同事第一次非正式见面。
- 实用任务：自然开启对话、说明合作关联，并给对方退出空间。
- 隐藏风险：过度推销、查户口式提问或只顾讲自己。
- 训练技能：职场寒暄、关系建立、粤语语气。

### P05 阿朗：“得闲搞”到底几时搞

- 场景：蓝调时刻的办公室走廊，跨团队交付仍未确认。
- 实用任务：把模糊口头承诺收束成负责人和时间点。
- 隐藏风险：过度催促损害关系，或继续接受没有日期的答复。
- 训练技能：委婉跟进、行动确认、书面收口。

### P06 何太：客户临时加需求

- 场景：下午项目会议舱，客户要求免费加入额外功能。
- 实用任务：不直接拒绝客户，同时明确范围、成本和交换条件。
- 隐藏风险：为了显得配合而无条件答应，造成团队失控。
- 训练技能：范围管理、边界谈判、条件式承诺。

### P07 陈嘉敏：高层只给你一分钟

- 场景：中环决策会议室，试点结果进入管理层决策。
- 实用任务：用“结论—证据—下一步”在一分钟内提出建议。
- 隐藏风险：从背景讲起、堆数据，最后没有清晰请求。
- 训练技能：高层汇报、证据压缩、明确行动请求。

## 体验结构

```text
首页
├── 五幕故事：保留原比赛演示主线
└── 情境训练库
    ├── 角色 / 技能 / 难度信息
    ├── 选择一个真实任务
    ├── 预写策略或自由回答
    ├── DeepSeek 角色反应
    ├── 港话通本地语境评分与改写
    ├── 任务复盘与可执行模板
    └── 重试 / 返回训练库
```

## AI 深度

- DeepSeek 根据人物利益、任务约束、玩家状态和本轮表达生成即时反应及
  关系后果。
- 港话通独立评价自然度、礼貌度和商务适配，并给出保持原意的香港表达。
- 训练结果显示“任务是否完成”，而不只显示语言分数。
- 每个情境提供一条可直接迁移到现实工作的行动模板。
- 标准预写路径始终可离线完成；双模型不可用时不阻断训练。

## 不改变的边界

- 原五幕 `nextSceneId` 主线不变。
- 训练库是独立案例，不由模型创建或跳转。
- 所有新人物图继续使用已批准角色锚点保持身份一致。
- 不保存自由回答原文，不向模型发送 API 密钥或个人资料。
